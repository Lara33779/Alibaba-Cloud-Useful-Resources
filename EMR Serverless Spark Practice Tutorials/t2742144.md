Use third-party Python libraries in a notebook {#2c55058f528al}
===============================================================

Third-party Python libraries are often used to enhance the data processing and analysis capabilities of interactive PySpark jobs that run in notebooks. This topic describes how to install third-party Python libraries in a notebook. {#9a56b0ea174gu}

**Background information** {#f3f6a635b48et}
-------------------------------------------

When you develop interactive PySpark jobs, you can use third-party Python libraries to enable more flexible and easier data processing and analysis. The following table describes the methods to use third-party Python libraries in a notebook. You can select a method based on your business requirements. {#6f601ee8bbinl}
{#ad40b69c9dzfx}{#a4ee29e755bqn}{#373de4ccbc05c}{#7190088160k5v}

|----------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Method**                                                                                                     | **Scenario**                                                                                                                                                                                                                                        |
| [Method 1: Run the pip command to install Python libraries](#8321512e3efes){#66b219af8axt2}                    | You want to process variables that are not related to Spark in a notebook, such as the return values calculated by Spark or custom variables. {#e306801a51kt6} **Important** You must reinstall the libraries after you restart a notebook session. |
| [Method 2: Create a runtime environment to define a custom Python environment](#58909fd68fmq1){#c8a444e18c1t7} | You want to use third-party Python libraries to process data in PySpark jobs, and you want the third-party libraries to be preinstalled each time a notebook session is started.                                                                    |
| [Method 3: Add Spark configurations to create a custom Python environment](#43103b56e5e6f){#114e343ab9bwc}     | You want to use third-party Python libraries to process data in PySpark jobs. For example, you use third-party Python libraries to implement Spark distributed computing.                                                                           |

### **Method 1: Run the pip command to install Python libraries** {#616eb449b38m9}

1. Go to the configuration tab of a notebook. {#17d9f910e327x}

   1. Log on to the [E-MapReduce (EMR) console](https://emr-next.console.aliyun.com/#/region/cn-hangzhou/resource/all/overview ""){#398c4c9c255xo}.

      {#ace3797f737cc}
   {#0f152a814bh9q}
   2. In the left-side navigation pane, choose **EMR Serverless** \> **Spark** .

      {#b166c7854bir0}
   {#0f152a834bqgu}
   3. On the **Spark** page, find the desired workspace and click the name of the workspace.

      {#b166c7864bl2h}
   {#0f152a854b8ko}
   4. In the left-side navigation pane of the **EMR Serverless Spark** page, click **Data Development** .

      {#b313fd21232af}
   {#0f152a874bya0}
   5. Double-click the notebook that you developed.

      {#4727c0cd2cfya}
   {#82e93ebcdewke}

   {#f15917c165edp}{#5125c9dc4bwdu}
{#5125c9dc4bwdu}
2. In a Python cell of the notebook, enter the following command to install the scikit-learn library and click the ![image](../images/p819092.png) icon. {#c36224537dauc}

   ```python
   pip install scikit-learn
   ```

   {#4014aa2b7cynh}{#28dcb196a85d2}
{#28dcb196a85d2}
3. Add a new Python cell, enter the following command in the cell, and then click the ![image](../images/p819092.png) icon. {#c40edd6eb6bch}

   ```python
   # Import datasets from the scikit-learn library. 
   from sklearn import datasets
   
   # Load the built-in dataset, such as the Iris dataset. 
   iris = datasets.load_iris()
   X = iris.data # The feature data.
   y = iris.tar get # The tag.
   
   # Divide datasets. 
   from sklearn.model_selection import train_test_split
   
   # Divide the datasets into training sets and test sets. 
   X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)
   
   # Use the support vector machine (SVM) model for training. 
   from sklearn.svm import SVC
   
   # Create a classifier instance. 
   clf = SVC(kernel='linear') # Use a linear kernel. 
   
   # Train the model. 
   clf.fit(X_train, y_train)
   
   # Use the trained model to make predictions. 
   y_pred = clf.predict(X_test)
   
   # Evaluate the model performance. 
   from sklearn.metrics import classification_report, accuracy_score
   
   print(classification_report(y_test, y_pred))
   print("Accuracy:", accuracy_score(y_test, y_pred))
   ```

### **Method 2: Create a runtime environment to define a custom Python environment** {#b514433571o8j}

#### Step 1: Create a runtime environment {#ed835df889pl3}

1. Go to the Runtime Environments page. {#b82909b149zt1}

   1. Log on to the [EMR console](https://emr-next.console.aliyun.com/#/region/cn-hangzhou/resource/all/overview){#b166c7824bsb1}.

      {#23e93dd636gvr}
   {#d5308c981bs9z}
   2. In the left-side navigation pane, choose **EMR Serverless** \> **Spark** .

      {#fe4a6ca092pyh}
   {#7ba3c7ca03mqn}
   3. On the **Spark** page, find the desired workspace and click the name of the workspace.

      {#510a845b5226h}
   {#d8ba4e2e07nh0}
   4. In the left-side navigation pane of the **EMR Serverless Spark** page, click **Runtime Environments** .

      {#e1ade5e55ap9q}
   {#e1ff9f1f4fnc1}

   {#b0f0bca5f8x6i}{#4e5a2cd7f7k8m}
{#4e5a2cd7f7k8m}
2. Click **Create Runtime Environment** .

   {#8a294475648uf}
{#492d0cea67z4f}
3. On the **Create Runtime Environment** page, configure the Name parameter. Then, click **Add Library** in the Libraries section. {#52d59845b6pja}

   For more information, see [Manage runtime environments](t2804452.md#){#17c81f4e5dkhf}.
   {#3c1b9f788872d}
{#7a5444c3241au}
4. In the **Create Library** dialog box, set the **Source Type** parameter to **PyPI** , configure the PyPI Package parameter, and then click **OK** . {#1d64e6f45c28k}

   Specify the library name and version in the required format for the **PyPI Package** parameter. If you do not specify a version, the library of the latest version is installed. Example: `scikit-learn`.
   {#5645cfb551v0v}
{#6fa9aaddef7fj}
5. Click **Create** . {#eeba88c977jar}

   The system starts to initialize the runtime environment after you click Create.

### **Method 3: Add Spark configurations to create a custom Python environment** {#7cd0447b483w9}

If you use this method, make sure that ipykernel of 6.29 or later is installed, and jupyter_client of 8.6 or later is installed. The Python version is 3.8 or later, and the environment is packaged in Linux. {#8530b767ed2kz}

#### **Step 1: Create and deploy a Conda environment** {#61de083685q29}

1. Run the following commands to install Miniconda: {#8200622efe6yu}

   ```bash
   wget https://repo.continuum.io/miniconda/Miniconda3-latest-Linux-x86_64.sh
   chmod +x Miniconda3-latest-Linux-x86_64.sh
   
   ./Miniconda3-latest-Linux-x86_64.sh -b
   source miniconda3/bin/activate
   ```

   {#4d39dff1351rx}{#7922555d56d6b}
{#7922555d56d6b}
2. Create a Conda environment for using Python 3.8 and NumPy. {#8de7fc13323n9}

   ```bash
   # Create a Conda environment and activate the environment.
   conda create -y -n pyspark_conda_env python=3.8
   conda activate pyspark_conda_env
   # Install third-party libraries.
   pip install numpy \
   ipykernel~=6.29 \
   jupyter_client~=8.6 \
   jieba \
   conda-pack
   # Package the environment.
   conda pack -f -o pyspark_conda_env.tar.gz
   ```

   {#a8ab1867d3dsr}{#93f583a84akiu}
{#93f583a84akiu}

{#19e5566180fjn}

#### **Step 2: Upload the resource file to OSS** {#a51f052da19l4}

Upload the `pyspark_conda_env.tar.gz` package to Object Storage Service (OSS) and copy the complete OSS path of the package. For more information, see [Simple upload](t4361.md#){#15aad11acfrdk}.

#### **Step 3: Configure and start the notebook session** {#275251387fjr1}

**Note**

You must stop a session before you modify the session.

1. Go to the Notebook Sessions tab. {#cb716366f4tvk}

   1. In the left-side navigation pane of the **EMR Serverless Spark** page, choose **Operation Center** \> **Sessions** .

      {#1610fb6380zzu}
   {#aa9a4a379dd94}
   2. Click the **Notebook Sessions** tab.

      {#86a51ffbddbv6}
   {#85f52d3480y0i}

   {#3d62c03f83xik}{#ed191404aafwc}
{#ed191404aafwc}
2. Find the desired session and click **Edit** in the Actions column.

   {#9b43557efap34}
{#ba6895adf2fx8}
3. On the Modify Notebook Session page, add the following configurations to the **Spark Configuration** field and click **Save Changes** . {#fbc2a121202db}

   ```xml
   spark.archives  oss://<yourBucket>/path/to/pyspark_conda_env.tar.gz#env
   spark.pyspark.python ./env/bin/python
   ```

   {#5b04818f19gwm}
   **Note**

   Replace `<yourBucket>/path/to` in the code with the OSS path that you copied in the previous step.
   {#1963c2241endv}
{#1963c2241endv}
4. In the upper-right corner of the page, click **Start** .

   {#9158f6e848typ}
