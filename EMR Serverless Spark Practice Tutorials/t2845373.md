Use Power BI to connect to EMR Serverless Spark and visualize data {#ea537195d8l8p}
===================================================================================

Power BI is a centralized, extendable self-service and enterprise business intelligence (BI) platform. You can use Power BI to connect to data sources for data modeling, visualized analysis, and personalized reporting. This topic describes how to connect to E-MapReduce (EMR) Serverless Spark to visualize and analyze data. {#3c42369e0axph}

**Limits** {#bef8b3e4071js}
---------------------------

You cannot access the data catalogs or tables of Paimon and Iceberg.

**Prerequisites** 
--------------------------------------

* A Power BI client is downloaded and installed. For more information, see [Microsoft Power BI](https://powerbi.microsoft.com/en-us/downloads/ ""){#5e82490c9fjyx}.

  {#51248eec55myp}

* A Spark Thrift Server and its token are created. For more information, see the [Create a Spark Thrift Server](t2763582.md#57f614bc81p5q){#6132fcb2bdfuy} and [Create a token](t2763582.md#ff19c46bcac8g){#5fd06bacf2dgv} sections in the "Manage Spark Thrift Servers" topic.

  {#a440a28ad2vkd}

**Use Power BI to connect to EMR Serverless Spark** {#18fe0d2851n0r}
--------------------------------------------------------------------

This section describes how to connect to EMR Serverless Spark by using different methods. You can select a method based on your business requirements. If you use Open Database Connectivity (ODBC) to connect to EMR Serverless Spark, you must install and configure ODBC. {#6adf0b9a37xwc}

### **Use ODBC to connect to EMR Serverless Spark** {#f6fc26f4f9hj9}

1. [Download](https://www.microsoft.com/en-us/download/details.aspx?id=49883){#fd1973e0afntu} and install the Microsoft Spark ODBC driver.

   {#209fb4304b65t}
{#c338716efc7zd}
2. Configure the ODBC driver. {#2fcd07a77djrl}

   1. Open the ODBC driver. On the **User DSN** tab, click **Add** .

      {#ae3574e8d1w86}
   {#43a9e32e94072}
   2. In the **Create New Data Source** dialog box, select **Microsoft Spark ODBC Driver** and click **Finish** . {#e5c5b67300m3p}

      ![image](../images/p902355.png)
      {#2b7c6630bcnpt}
   {#743b4a5158glk}
   3. In the **Microsoft Spark ODBC Driver DSN Setup** dialog box, configure the required parameters that are described in the following table and use the default values for other parameters. {#c21e0fed98i03}

      {#d35129c16cm6q}{#64744e3476hdk}{#1d606f34a4cf7}{#e86a85190fuzf}{#51d448ec11rn6}{#f3f6202dccazt}

      |----------------------|----------------------------------------------------------------------------------------------------------------------------------------------------|
      | **Parameter**        | **Description**                                                                                                                                    |
      | **Date Source Name** | The name of the data source. Example: serverless_spark_test.                                                                                       |
      | **Host(s)**          | The **internal endpoint** or the **public endpoint** of the Spark Thrift Server that you created. {#074b3dc8869nt} ![image](../images/p900596.png) |
      | **Mechanism**        | The authentication method. Select **User Name and Password** .                                                                                     |
      | **User Name**        | The name of the token that you created on the **Tokens** tab of the Spark Thrift Server.                                                           |
      | **Password**         | The token that you copied from the **Tokens** tab of the Spark Thrift Server.                                                                      |

      {#4e01ede092nw1}{#b00b998c28mch}
   {#b00b998c28mch}
   4. Click **HTTP Options** . In the dialog box that appears, enter `/cliservice` in the **HTTP Path** field and click **OK** . {#9afc049133ohl}

      ![image](../images/p902365.png)
      {#fde3cf71dc0pg}
   {#fb13760668a5c}
   5. Optional. Click **Advanced Options** . In the dialog box that appears, select **Get Tables With Query** and click **OK** . {#188209ff23d39}

      **Note**

      If Paimon or Iceberg tables exist in the default catalog, we recommend that you perform this operation.

      ![image](../images/p902372.png)
      {#541f10b9b1wil}
   {#5c509c36eb7zr}
   6. In the **Microsoft Spark ODBC Driver DSN Setup** dialog box, click **Test** to test the connectivity. {#788a949f84wom}

      If the returned information contains `SUCCESS`, the ODBC driver is connected to the specific Serverless Spark Thrift Server. {#85379e0277k0r}

      ![image](../images/p902385.png)
      {#48eec2862ewwa}
   {#ee2f465e753ci}
   7. In the **Microsoft Spark ODBC Driver DSN Setup** dialog box, click **OK** to save the DSN configurations.

      {#62f7358d88zgv}
   {#7e1ed02685mfq}

   {#88baf672f759k}{#1d46f4743dxo3}
{#1d46f4743dxo3}
3. Connect to EMR Serverless Spark. {#bf9e59e4690kl}

   1. On the **Home** tab, click **Get data from other sources** in the **Select a data source or start with a blank report** section.

      {#6cf305401bxxf}
   {#71baf47e4fvh7}
   2. On the **All** tab of the **Get Data** dialog box, enter **ODBC** in the search box, click ODBC, and then click **Connect** . {#b5fb555c99w7r}

      ![image](../images/p902421.png)
      {#9872402e2aey5}
   {#cfec742ff90i4}
   3. In the dialog box that appears, select the serverless_spark_test data source form the drop-down list and click **OK** . {#472bf0ca816y6}

      ![image](../images/p902426.png)
      {#23a5eba3b9o2l}
   {#3edda0e51158q}
   4. On the **Windows** tab of the dialog box that appears, select **Use my current credentials** and click **Connect** . {#fea87573becrv}

      ![image](../images/p902441.png)
      {#061f0e065bmpr}
   {#03165d5cc71ch}

   {#2e3e874407r27}{#0dfe3c77a45q5}
{#0dfe3c77a45q5}
4. In the **Navigator** dialog box, select the table that you want to import and click **Load** . {#1a4482d01b6hc}

   ![image](../images/p902476.png)
   {#3386928b8d2am}
{#29bb3f7d3cmc7}

### **Use Spark to connect to EMR Serverless Spark** {#7f7d807d36arg}

1. On the **Home** tab, click **Get data from other sources** in the **Select a data source or start with a blank report** section.

   {#315c16d240jma}
{#1b01c43ffe3wo}
2. On the **All** tab of the **Get Data** dialog box, enter **Spark** in the search box, click Spark, and then click **Connect** . {#046d30d6f6mcb}

   ![image](../images/p902449.png)
   {#0a127dfa1b8xg}
{#79175dde0dujj}
3. In the dialog box that appears, configure the parameters and click **OK** . {#5ece4dc01bqhl}

   ![image](../images/p900454.png)Configure the parameters based on your business requirements. The following table describes the parameters. {#3105fee777dfb}
   {#b8f8b508dccdy}{#d641cd2ada6zj}{#91a53f46f41pp}

   |----------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   | **Parameter**              | **Description**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
   | **Server**                 | Enter a value in the `http//<endpoint>:<port>/cliservice/token/<token>` format.  {#54251495c87s7} * `<endpoint>`: the **public endpoint** or the **internal endpoint** of the Spark Thrift Server that you created. {#30b9e97da4l7w} {#2d760744c39ym} * `<port>`: the port number. If you use the public endpoint to connect to the Spark Thrift Server, the port number is 443. If you use the internal endopint to connect to the Spark Thrift Server, the port number is 80. {#df1b0c450963j} {#9b2f7677e0789} * `<token>`: the token that you copied from the **Tokens** tab of the Spark Thrift Server. {#5446f81110z6t} {#f0c02801ddupx} {#a760767b6f6mq} |
   | **Protocol**               | Select **HTTP** .                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
   | **Data Connectivity Mode** | Valid values:{#7ed79b1d2cerf} * **Import** : copies data to Power BI. {#54e58f0ba0ocw} {#70678b301bwoa} * **DirectQuery** : dynamically requests data from the connected data source. {#5aef8a548emsx} {#719d9a311bj30} {#70678b321bazu} **Note** DirectQuery is more suitable in the following scenarios: {#7c58c5273a4il} * The data source contains a large amount of data. {#6c53213bfaui6} {#3bb809421bd8m} * Quasi-real-time data is required. {#b0d4232a4fyud} {#3bb809441bv2u} {#3bb809401b9m3}                                                                                                                                                         |
   | **Advanced Options**       | In this example, you do not need to configure the parameters in the Advanced Options (optional) section. Use the default values for the parameters. You can also configure the advanced parameters to configure the connection in a fine-grained manner based on your business requirements.                                                                                                                                                                                                                                                                                                                                                                    |

   {#4cc120a8f7nhv}
{#4cc120a8f7nhv}
4. In the dialog box that appears, configure the User name and Password parameters and click **Connect** . The following table describes the parameters. {#055d63a80c8jj}

   {#919e34b839wpj}{#9fcae8b9f98xg}{#4d044255c5usa}

   |---------------|------------------------------------------------------------------------------------------|
   | **Parameter** | **Description**                                                                          |
   | **User name** | The name of the token that you created on the **Tokens** tab of the Spark Thrift Server. |
   | **Password**  | The token that you copied from the **Tokens** tab of the Spark Thrift Server.            |

   {#004470de759pz}
{#004470de759pz}
5. In the **Navigator** dialog box, select the table that you want to import and click **Load** . {#86963a70658u7}

   ![image](../images/p902476.png)
   {#d8141d94a7fh8}
{#6f3f55b071jyy}
