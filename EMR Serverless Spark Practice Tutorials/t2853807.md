Implement StarRocks read and write operations in EMR Serverless Spark {#23ecf878e70sk}
======================================================================================

The official StarRocks provides a Spark connector for data reading and writing between Spark and StarRocks. Serverless Spark can add the corresponding configuration to connect to StarRocks during development. This topic introduces how to implement read and write operations for StarRocks in EMR Serverless Spark.{#a000e29726awh}

**Prerequisites** {#14f6b31472ull}
----------------------------------

* A Serverless Spark workspace is now in place. For more information, see [Create a workspace](t2488607.md#){#543578d2f5nqu}.

  {#8f9d71edeedd7}
{#d7fe41c2bblhy}
* You have successfully created an EMR Serverless StarRocks instance. For more information, see [Create an instance](t2285387.md#task-2285387){#3db09802b45dk}.

  {#b6e73b44347zo}
{#ea46f57beehl3}

{#e64bbe45e1fds}

**Limits** {#01eb7a8643sdo}
---------------------------

The version requirement for the Serverless Spark engine is esr-2.5.0, esr-3.1.0, esr-4.1.0, or later.{#791b3cc279w8l}

**Operation flow** {#e40117d2307xa}
-----------------------------------

### **Step 1: Obtain the Spark connector JAR and upload it to OSS** {#d4462d751f3a4}

1. Refer to [Read data from StarRocks using Spark connector](https://docs.starrocks.io/zh/docs/unloading/Spark_connector/#%E8%8E%B7%E5%8F%96-spark-connector){#d911ef71fafio}[Read data from StarRocks using Spark connector](https://docs.starrocks.io/docs/unloading/Spark_connector/){#9ecf9894adios} to select the appropriate method to download the corresponding version of the Spark connector JAR.{#894d074069dhu}

   For example, this topic chooses to directly download the precompiled JAR, which can be obtained from the [Maven Central Repository](https://repo1.maven.org/maven2/com/starrocks){#eb75c3f3ddex5} for different versions of the connector JAR package.{#a2f4b9e4c3vnt}
   **Note**

   The naming format for the connector JAR package is `starrocks-spark-connector-${spark_version}_${scala_version}-${connector_version}.jar`. For example, if you are using engine version esr-4.1.0 (Spark 3.5.2, Scala 2.12) and want to use version 1.1.2 of the connector, you can choose `starrocks-spark-connector-3.5_2.12-1.1.2.jar`.
   {#7cf7da6fd8g8b}
{#7cf7da6fd8g8b}
2. Upload the Spark connector JAR you downloaded to Alibaba Cloud OSS. For details on the upload process, see [Simple Upload](t4361.md#){#108401aee0950}.

### **Step 4: Read and write StarRocks through Serverless Spark** {#964fe85678unx}

**Method 1: Use SQL sessions and Notebook sessions to read and write StarRocks** {#4d37a142532d9}
-------------------------------------------------------------------------------------------------

For more information on session types, see [Session Management](t2231770.md#){#8926113c71inm}.{#f531b25b302og}

**SQL sessions** {#6b4829d7daj2m}
---------------------------------

1. Write data to StarRocks through Serverless Spark.{#9debf2cec8x4w}

   1. Create an SQL session. For more information, see [Manage SQL Sessions](t2699789.md#){#2b56c7bc6ab6s}.{#a1baaf1aa450i}

      When creating a session, select the engine version corresponding to the StarRocks connector version. In **Network Connectivity** , select the network connectivity created in the previous step, and add the following parameters in **Spark Configuration** to load the Spark connector.{#0df9c48682pgf}

      ```xml
      spark.user.defined.jars  oss://<bucketname>/path/connector.jar
      ```

      {#a34074e98bata}

      Here, `oss://<bucketname>/path/connector.jar` is the path of the Spark connector you uploaded to OSS in Step 1. For example, `oss://emr-oss/spark/starrocks-spark-connector-3.5_2.12-1.1.2.jar`.
      {#92656b355fhma}
   {#92656b355fhma}
   2. On the **Data Development** page, create a task of type **SQL** \> **SparkSQL** , and then select the created SQL session in the upper right corner.{#0f64fe8665639}

      For additional operations, see [SparkSQL Development](t2499287.md#){#f5e1237bf7y2y}.
      {#bbc5953167rzj}
   {#411d4409a5iki}
   3. Copy the following code into the newly added SparkSQL tab, modify the relevant parameter information as needed, and then click **Run** .{#4e35adcacf6xk}

      ```sql
      CREATE TABLE score_board
      USING starrocks
      OPTIONS
      (
        "starrocks.table.identifier" = "testdb.score_board",
        "starrocks.fe.http.url" = "<fe_host>:<fe_http_port>",
        "starrocks.fe.jdbc.url" = "jdbc:mysql://<fe_host>:<fe_query_port>",
        "starrocks.user" = "<user>",
        "starrocks.password" = "<password>"
      );
      
      INSERT INTO `score_board` VALUES (1, "starrocks", 100), (2, "spark", 100);
      ```

      {#5bbae08f4brgx}

      The parameter descriptions are as follows:{#196894e0ffhu0}
      * `<fe_host>`: The internal or public network address of the FE in the Serverless StarRocks instance. You can view it in the **Instance Details** page in the **FE Details** area.{#08ce51c06fsf6}

        * If using an internal network address, ensure it is within the same VPC.

          {#40609f272crtd}
        {#a34bee6636rcc}
        * When utilizing a public network address, make sure the security group rule permits communication through the appropriate port. For more information, see [Network access and security settings](t2295013.md#section-krm-eoh-zch){#e0ffef300etdl}.

          {#d71351336ek2h}
        {#604b6ceb7do2n}

        {#cbbb6d2bb2zyh}{#2360d55076z4f}
      {#2360d55076z4f}
      * `<fe_http_port>`: The HTTP port of the FE in the Serverless StarRocks instance (default is 8030). You can view it in the **Instance Details** page in the **FE Details** area.

        {#574900070bkp0}
      {#529e952e9cobh}
      * `<fe_query_port>`: The query port of the FE in the Serverless StarRocks instance (default is 9030). You can view it in the **Instance Details** page in the **FE Details** area.

        {#780dc2cc92fsc}
      {#5bb4ee7d5f31n}
      * `<user>`: This represents the username for the Serverless StarRocks instance. A default admin user with administrator permissions is provided. You can also create a new user on the **User Management** page for connection purposes. For more information on user creation, see [Manage users and data authorization](t2286650.md#section-14j-rlq-16o){#47aeb84862elb}.

        {#d6d2ecf939801}
      {#35da6ce16910e}
      * `<password>`: The password corresponding to the user `<user>`.

        {#9157f0d36dcyp}
      {#a992211356xzl}

      {#1cd236c061b2t}{#8e3745ef3csb7}
   {#8e3745ef3csb7}

   {#ad5bbedd9ceik}{#bab1cc5d8d6ly}
{#bab1cc5d8d6ly}
2. Query the data written through Serverless Spark.{#7eee48eddcazg}

   In this example, we created a temporary view `test_view` in the above SparkSQL task, and then queried the data of the `score_board` table through this view. Copy the following code into the newly added SparkSQL tab, select the code, and then click **Run Selected** .{#014293f00cktg}

   ```sql
   CREATE TEMPORARY VIEW test_view
   USING starrocks
   OPTIONS
   (
      "starrocks.table.identifier" = "testdb.score_board",
      "starrocks.fe.http.url" = "<fe_host>:<fe_http_port>",
      "starrocks.fe.jdbc.url" = "jdbc:mysql://<fe_host>:<fe_query_port>",
      "starrocks.user" = "<user>",
      "starrocks.password" = "<password>"
   );
   
   SELECT * FROM test_view;
   ```

   3. Copy the following code into the newly added Python cell of the Notebook, and click **Run** .{#811f4c9fa44an}

      ```python
      # Replace with your Serverless StarRocks configuration.
      fe_host = "<fe_host>"
      fe_http_port = "<fe_http_port>"
      fe_query_port = "<fe_query_port>"
      user = "<user>"
      password = "<password>"
      
      # Create table
      create_table_sql = f"""
      CREATE TABLE score_board
      USING starrocks
      OPTIONS (
        "starrocks.table.identifier" = "testdb.score_board",
        "starrocks.fe.http.url" = "{fe_host}:{fe_http_port}",
        "starrocks.fe.jdbc.url" = "jdbc:mysql://{fe_host}:{fe_query_port}",
        "starrocks.user" = "{user}",
        "starrocks.password" = "{password}"
      )
      """
      
      spark.sql(create_table_sql)
      
      # Insert data
      insert_data_sql = """
      INSERT INTO `score_board` VALUES (1, "starrocks", 100), (2, "spark", 100)
      """
      
      spark.sql(insert_data_sql)
      ```

2. Query the data written through Serverless Spark.{#501fcdaf822oe}

   In this example, we added a Python cell, created a temporary view `test_view`, and then queried the data of the `score_board` table through this view. Copy the following code into the newly added Python cell, and then click the ![image](../images/p916799.png) icon.{#257aab3818qkc}

   ```sql
   # Create view
   create_view_sql=f"""
   CREATE TEMPORARY VIEW test_view
   USING starrocks
   OPTIONS (
     "starrocks.table.identifier" = "testdb.score_board",
     "starrocks.fe.http.url" = "{fe_host}:{fe_http_port}",
     "starrocks.fe.jdbc.url" = "jdbc:mysql://{fe_host}:{fe_query_port}",
     "starrocks.user" = "{user}",

   """
   spark.sql(create_view_sql)
     
   # Query
   query_sql="SELECT * FROM test_view"
   ```
