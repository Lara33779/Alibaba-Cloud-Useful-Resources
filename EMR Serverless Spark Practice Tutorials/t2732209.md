Read data from and write data to MaxCompute in EMR Serverless Spark {#ed21048b2eltr}
====================================================================================

E-MapReduce (EMR) Serverless Spark provides built-in MaxCompute data sources based on the Spark DataSource V2 API. If you want to connect a job to MaxCompute, you need to only add specific configurations when you develop the job. This topic describes how to read data from and write data to MaxCompute in EMR Serverless Spark. {#64461c1dda2mo}

**Background information** {#830cc3c51544u}
-------------------------------------------

MaxCompute, formerly known as ODPS, is a fast and fully managed computing platform for large-scale data warehousing. MaxCompute can process up to exabytes of data. MaxCompute supports batch computing and storage of structured data and provides various data warehousing solutions and big data analysis and modeling services. For more information about MaxCompute, see [What is MaxCompute?](t11916.md#concept-qbk-1kv-tdb){#c53b40a946161}

**Prerequisites** {#9afcf2057d8kq}

* An EMR Serverless Spark workspace is created. For more information, see [Create a workspace](t2488607.md#){#7c6af6f01164r}.

* A MaxCompute project is created. For more information, see [Create a MaxCompute project](t11944.md#){#0bc166b03cgb5}.

### Create a Spark SQL job to write data to the MaxCompute project {#897fc88276l66}

1. In the left-side navigation pane of the EMR Serverless Spark page, click **Data Development** .

   {#b1076c0623bha}
{#a5b2d748b9f0a}
2. On the **Development** tab, click **Create** .

   {#ce4a28bf01f1f}
{#b51bdb1fb6w19}
3. Create a Spark SQL job. {#9b840fdb7c5y0}

   1. In the Create dialog box, specify a job name in the Name field, choose SQL \> SparkSQL from the Type drop-down list, and then click **OK** . In this example, the job is named mc_load_task.

      {#a3aae54704bhp}
   {#ca0ff2bc3a1ky}
   2. On the configuration tab of the mc_load_task job, copy the following code to the code editor: {#70dc2090a6i7x}

      ```sql
      CREATE TABLE odps.default.customer_total_return AS (
        SELECT
          sr_customer_sk AS ctr_customer_sk,
          sr_store_sk AS ctr_store_sk,
          sum(sr_return_amt) AS ctr_total_return
        FROM
          odps.bigdata_public_dataset.tpcds_10g.store_returns,
          odps.bigdata_public_dataset.tpcds_10g.date_dim
        WHERE
          sr_returned_date_sk = d_date_sk
          AND d_year = 2000
        GROUP BY
          sr_customer_sk,
          sr_store_sk
      );
      
      SELECT * FROM odps.default.customer_total_return;
      ```

#### Create a Spark SQL job or a notebook to query data from the MaxCompute project {#f5e31ae43ap0p}

This section describes how to create a Spark SQL job or a notebook to query data in a TPC-DS public dataset in the MaxCompute project. {#38ee31f76az69}

#### Create a Spark SQL job to query data from the MaxCompute project {#c1b1fa51a9u77}

1. In the left-side navigation pane of the EMR Serverless Spark page, click **Data Development** .

   {#86d151704bywc}
{#758b44cf83czk}
2. On the **Development** tab, click **Create** .

   {#391e98a065ga9}
{#ae45ca52747r8}
3. Create a Spark SQL job. {#46978627013l8}

   1. In the Create dialog box, specify a job name in the Name field, choose **SQL** \> **SparkSQL** from the Type drop-down list, and then click **OK** . In this example, the job is named mc_read_sql_task.

      {#784fa8c065fo7}
   {#c847226372pkk}
   2. On the configuration tab of the mc_read_sql_task job, copy the following code to the code editor: {#06c6f0d876zv8}

      ```sql
      WITH customer_total_return AS (
        SELECT
          sr_customer_sk AS ctr_customer_sk,
          sr_store_sk AS ctr_store_sk,
          sum(sr_return_amt) AS ctr_total_return
        FROM
          odps.bigdata_public_dataset.tpcds_10g.store_returns,
          odps.bigdata_public_dataset.tpcds_10g.date_dim
        WHERE
          sr_returned_date_sk = d_date_sk
          AND d_year = 2000
        GROUP BY
          sr_customer_sk,
          sr_store_sk
      )
      SELECT
        c_customer_id
      FROM
        customer_total_return ctr1,
        odps.bigdata_public_dataset.tpcds_10g.store,
        odps.bigdata_public_dataset.tpcds_10g.customer
      WHERE
        ctr1.ctr_total_return > (
          SELECT
            avg(ctr_total_return) * 1.2
          FROM
            customer_total_return ctr2
          WHERE
            ctr1.ctr_store_sk = ctr2.ctr_store_sk
        )
        AND s_store_sk = ctr1.ctr_store_sk
        AND s_state = 'TN'
        AND ctr1.ctr_customer_sk = c_customer_sk
      ORDER BY
        c_customer_id
      LIMIT
        100;
      ```

      {#bf459bbf829kv}{#05a4044c70rqb}
   {#05a4044c70rqb}
   3. Select a database from the Default Database drop-down list and the mc_sql_compute SQL session that you created in [Step 1: Create a session to connect to the MaxCompute project](#c22732fe88vba){#61318db3e3k3y} from the SQL Sessions drop-down list.

      {#2286d0f1e5nds}
   {#5db80a2407tv5}
   4. Click **Run** to run the Spark SQL job. {#09cf39904b07k}

      After the job is run, the returned data is displayed on the **Execution Results** tab. {#052c2f907dop3}
