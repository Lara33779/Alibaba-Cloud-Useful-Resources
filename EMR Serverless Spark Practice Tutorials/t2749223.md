Use Hudi in EMR Serverless Spark {#e8fbe8b344mtg}
=================================================

Apache Hudi is a data lake framework that allows you to update and delete data in Hadoop compatible file systems. Hudi also allows you to consume changed data. For more information, see [Apache Hudi](https://hudi.apache.org/){#3149d4950cq4w}. This topic describes how to read data from and write data to a Hudi table in EMR Serverless Spark. {#08f2d24ff0mva}

Prerequisites {#d0851f0fa449v}
------------------------------

A workspace is created. For more information, see [Create a workspace](t2488607.md#){#237c57d04cpoh}.

Procedure {#3447a1e231ybc}
--------------------------

### **Step 1: Create an SQL session** {#96bb726b77h7a}

1. Go to the Sessions page. {#9c10d75ee20oh}

   1. Log on to the [EMR console](https://emr-next.console.aliyun.com/#/region/cn-hangzhou/resource/all/overview){#b6d7c2902dddl}.

      {#3628691aa3fy7}
   {#0f152a814bh9q}
   2. In the left-side navigation pane, choose **EMR Serverless** \> **Spark** .

      {#b166c7854bir0}
   {#0f152a834bqgu}
   3. On the **Spark** page, click the name of the workspace that you want to manage.

      {#b166c7864bl2h}
   {#0f152a854b8ko}
   4. In the left-side navigation pane of the **EMR Serverless Spark** page, choose **Operation Center** \> **Sessions** .

      {#c79985045dxzs}
   {#0f152a874bya0}

   {#f15917c165edp}{#5e8eb349fax6e}
{#5e8eb349fax6e}
2. On the **SQL Sessions** tab, click **Create SQL Session** .

   {#da24ced066cd3}
{#caa6ae8c0bqi1}
3. In the **Spark Configuration** section of the **Create SQL Session** page, add the following code and click **Create** . For more information, see [Manage SQL sessions](t2699789.md#){#9a3169f19f9q6}. {#5c837f2bcarfj}

   ```xml
   spark.sql.extensions             org.apache.spark.sql.hudi.HoodieSparkSessionExtension
   spark.sql.catalog.spark_catalog  org.apache.spark.sql.hudi.catalog.HoodieCatalog
   spark.serializer                 org.apache.spark.serializer.KryoSerializer
   spark.jars                       /opt/hudi/hudi-spark.jar
   ```

   {#0828e975a60ox}{#d6ed0ec5845j6}
{#d6ed0ec5845j6}

{#5edbe5fe9cutf}

### **Step 2: Read data from and write data to a Hudi table** {#70e87ec143i28}

1. Go to the data development page of EMR Serverless Spark. {#29bd7852f4biq}

   In the left-side navigation pane of the **EMR Serverless Spark** page, click **Data Development** .
   {#42543ba9bel3c}
{#0203fcf8f53rp}
2. On the **Development** tab, click the ![image](../images/p916811.png) icon.

   {#336e9a4065j3m}
{#1ce806c04b9hl}
3. In the **Create** dialog box, set the Name parameter to users_task, use the default value SparkSQL for the Type parameter, and then click **OK** .

   {#784fa8c065fo7}
{#b6f0d65558qut}
4. On the users_task tab, copy the following code to the code editor: {#d6d26f11e17aq}

   ```sql
   CREATE DATABASE IF NOT EXISTS ss_hudi_db;
   
   CREATE TABLE ss_hudi_db.hudi_tbl (id INT, name STRING) USING hudi TBLPROPERTIES (
     type = 'cow',
     primaryKey = 'id'
   );
   
   INSERT INTO ss_hudi_db.hudi_tbl VALUES (1, "a"), (2, "b");
   
   SELECT id, name FROM ss_hudi_db.hudi_tbl ORDER BY id;
   
   DROP TABLE ss_hudi_db.hudi_tbl;
   
   DROP DATABASE ss_hudi_db;
   ```

   {#9b7b2caeb155i}{#910db9b2dfaw6}
{#910db9b2dfaw6}
5. Select a database from the Default Database drop-down list and the created SQL session from the SQL Sessions drop-down list.

   {#d808284f0f4or}
{#76addbae29qjj}
6. Click **Run** . The following figure shows the output. {#8d14c717e7hhu}

   ![image](../images/p827586.png)
   {#025203eb44dfo}
{#161838724e9f5}
