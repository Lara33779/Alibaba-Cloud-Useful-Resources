Use EMR Serverless Spark to submit a PySpark streaming job {#ba87d94710xi8}
===========================================================================

With the rapid development of big data, the stream processing technology has become essential for real-time data analysis. E-MapReduce (EMR) Serverless Spark is a powerful and scalable platform that simplifies real-time data processing and saves the trouble of managing servers, thereby improving efficiency. This topic describes how to use EMR Serverless Spark to submit a PySpark streaming job. You can understand the usability and maintainability of EMR Serverless Spark in stream processing based on this topic. {#db4defef2fo4n}

**Prerequisites** {#1c839c056b9pd}
----------------------------------

An EMR Serverless Spark workspace is created. For more information, see [Create a workspace](t2488607.md#){#61d5798aefrv5}.

**Procedure** {#86676149ffmdy}
------------------------------

### **Step 1: Create** a Dataflow cluster and generate messages {#e5600b1bc4u8e}

1. Log on to the EMR console and create a Dataflow cluster that contains the Kafka service on the EMR on ECS page. For more information, see [Create a cluster](t2136630.md#){#454afb0bb10dr}.

   {#9d8fb6a6f5cbc}
{#e9b403c14d444}
2. Log on to the master node of the EMR cluster. For more information, see [Log on to a cluster](t2139059.md#){#3056ca0667eaz}.

   {#85bc08a01eptf}
{#909ac18756bfe}
3. Run the following command to switch the directory: {#ab8bf19d82nf7}

   ```sh
   cd /var/log/emr/taihao_exporter
   ```

   {#1acda0b4ddgvx}{#628e9e40b3d7i}
{#628e9e40b3d7i}
4. Run the following command to create a topic: {#9ade9f29a1wv1}

   ```sh
   # Create a topic named taihaometrics, with 10 partitions and a replica factor of 2. 
   kafka-topics.sh --partitions 10 --replication-factor 2 --bootstrap-server core-1-1:9092 --topic taihaometrics --create
   ```

   {#a6b9910472bw9}{#d7a6f7f7d24ts}
{#d7a6f7f7d24ts}
5. Run the following command to send messages: {#44f92886b3bkg}

   ```sh
   # Use the kafka-console-producer CLI to send messages to the taihaometrics topic. 
   tail -f metrics.log | kafka-console-producer.sh --broker-list core-1-1:9092 --topic taihaometrics
   ```

   {#0888590d99xdt}{#de10935293jci}
{#de10935293jci}

{#f8b5adb7de50p}

### Step 2: Create a network connection {#e31ff6b5dcp35}

1. Go to the Network Connections page. {#0b739e3c7fcyy}

   1. In the left-side navigation pane of the EMR console, choose **EMR Serverless** \> **Spark** .

      {#338f95e024o28}
   {#02f797079dtup}
   2. On the **Spark** page, find the desired workspace and click the name of the workspace.

      {#38ed49004bsqn}
   
   3. In the left-side navigation pane of the **EMR Serverless Spark** page, click **Network Connections** .

      {#86d151704bywc}
   {#0703bc814b30d}

   {#a6e6756b3cali}{#2a8acc238fwvw}
{#2a8acc238fwvw}
2. On the **Network Connections** page, click **Create Network Connection** .

   {#49289099a5xcr}
{#f9007dad076hn}
3. In the **Create Network Connection** dialog box, configure parameters and click **OK** . The following table describes the parameters. {#48c0b80191g6i}

   {#e503485744v4o}{#7f136ae6d9p5a}{#d5afbc930fmr1}{#709d43adbbl17}

   |---------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   | **Parameter** | **Description**                                                                                                                                                                                                                                                                            |
   | **Name**      | The name of the network connection. Example: connection_to_emr_kafka.                                                                                                                                                                                                                      |
   | **VPC**       | The virtual private cloud (VPC) in which your EMR cluster resides. {#947b0b94063gg} If no VPC is available, click **Create VPC** to create a VPC in the VPC console. For more information, see [Create and manage a VPC](t2435.md#){#bfa979e0f6gpy}.                                       |
   | **vSwitch**   | A vSwitch that is deployed in the VPC in which the EMR cluster is deployed. {#0c12bac3fdyqy} If no vSwitch is available in the current zone, click **vSwitch** to create a vSwitch in the VPC console. For more information, see [Create and manage a vSwitch](t2436.md#){#90f6b11a29zbc}. |

   {#1388c3d94afbu}

   If **Succeeded** is displayed in the **Status** column of the connection, the network connection is created.
   {#9240e6a1b2dkg}
{#c1a3bfa951aep}

{#0176d123d4t3t}

### Step 3: Configure security group rules for the EMR cluster {#12b28f46e5fh2}

1. Obtain the CIDR block of the vSwitch to which a cluster node is connected. {#278962c08blad}

   On the **Nodes** tab, click the name of a node group to view the associated vSwitch. Then, log on to the [VPC console](https://vpcnext.console.aliyun.com/vpc ""){#af361972b1tuq} and obtain the CIDR block of the vSwitch on the **vSwitch** page. {#de16db3d55een}

   ![image](../images/p806302.png)
   {#2c56ca36e3umd}
{#14d89a33b677f}
2. Configure security group rules. {#b746cc6668sk8}

   1. On the **EMR on ECS** page, find the desired cluster and click the name of the cluster.

      {#f7b7af6f62mzp}
   {#7b11438cb4hih}
   2. In the Security section of the **Basic Information** tab, click the link to the right of **Cluster Security Group** .

      {#b05fed0d26c0l}
   {#0f12e53520pey}
   3. On the Security Group Details page, click Add Rule, configure the Port Range and Authorization Object parameters, and then click **Save** in the Actions column. {#b975b6796edvj}

      {#e3fee24b880nx}{#95514cf9cddbp}

      |--------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
      | **Parameter**            | **Description**                                                                                                                                                                                                       |
      | **Port Range**           | The port number. In this example, enter 9092.                                                                                                                                                                         |
      | **Authorization Object** | The CIDR block of the vSwitch obtained in the previous step. {#436b1d1396e7c} **Important** To prevent attacks from external users, we recommend that you do not set the Authorization Object parameter to 0.0.0.0/0. |

      {#d50fd71c9bkfh}
   {#d50fd71c9bkfh}

   {#34d5d9eb4077n}{#a4145451ef6c7}
{#a4145451ef6c7}

{#bcfad6c59e8bn}

### Step 4: Upload JAR files to OSS {#63cda24982so5}

Decompress the [kafka.zip](https://help-static-aliyun-doc.aliyuncs.com/file-manage-files/en-US/20240903/hdxouy/kafka.zip){#77034f0ed94wn} package and upload all the obtained JAR files to Object Storage Service (OSS). For more information, see [Simple upload](t4361.md#){#0342dfc402k0a}.

### Step 5: Upload the resource file {#d9e28419c8sfi}

1. In the left-side navigation pane of the EMR Serverless Spark page, click **Files** .

   {#f9157b89d27zd}
{#e056625208v0n}
2. On the **Files** page, click **Upload File** .

   {#20c179d0655ht}
{#09383ce165gpg}
3. In the **Upload File** dialog box, click the area in the dotted line rectangle to select the [pyspark_ss_demo.py](https://help-static-aliyun-doc.aliyuncs.com/file-manage-files/en-US/20240903/absool/pyspark_ss_demo.py){#009b041b4fk8k} file, or drag the file to the area.

   {#a4d0df4066u0s}
{#221040f165rr7}

{#2eda71f49be19}

### Step 6: Create and start a streaming job {#7ae35b5597sqk}

1. In the left-side navigation pane of the EMR Serverless Spark page, click **Data Development** .

   {#f7cbb50d692un}
{#c5707c6d60reh}
2. Click **Create** .

   {#dde09af19110v}
{#9b518d3a851jb}
3. Enter a name in the Name field, choose **Streaming Job** \> **PySpark** from the Type drop-down list, and then click **OK** .

   {#9e4a8f13cbugl}
{#fab9a3484bm6h}
4. On the configuration tab that appears, configure parameters and click **Save** . The following table describes the parameters that you must configure. {#7c5db92c711fw}

   {#14986cb6f24gb}{#9aa162f8fd1jm}{#a29606949czib}{#67b1e10222q6a}{#ee62f743660cg}

   |---------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   | Parameter                 | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
   | **Main Python Resources** | Enter the path of the pyspark_ss_demo.py file that you uploaded on the **Files** page in the previous step.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
   | **Engine Version**        | Select the Spark version. For more information, see [Engine versions](t2607013.md#){#cd37ec3c61cqw}.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
   | **Execution Parameters**  | Enter the private IP address of the core-1-1 node in the EMR cluster. You can go to the **Nodes** tab of the EMR cluster and click the + icon to the left of the core node group to view the private IP address of the core-1-1 node.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
   | **Spark Configuration**   | Enter the Spark configurations. The following code provides an example of Spark configurations: {#a2c6725e4ea0g} ```yaml spark.jars oss://path/to/commons-pool2-2.11.1.jar,oss://path/to/kafka-clients-2.8.1.jar,oss://path/to/spark-sql-kafka-0-10_2.12-3.3.1.jar,oss://path/to/spark-token-provider-kafka-0-10_2.12-3.3.1.jar spark.emr.serverless.network.service.name connection_to_emr_kafka ``` {#7908dc2d12ngd} **Note** * `spark.jars`: specifies the path of the external JAR files that you want to load when the Spark job is running. Replace the value in the preceding code with the paths of all JAR files that you uploaded in Step 4. {#e1b4fb42be5y9} {#b63b4147c3vka} * `spark.emr.serverless.network.service.name`: specifies the name of the network connection. Replace the value in the preceding code with the name of the network connection that you created in Step 2. {#ed9c2eab31yp6} {#473ed7f37a2xw} {#1fe34a9100luc} |

   {#06c3a540668u2}{#26068ffb7307n}
{#26068ffb7307n}
5. Click **Publish** .

   {#7fe9119fa6lj5}
{#952704dc51hwj}
6. In the **Publish** dialog box, click **OK** .

   {#d1dd6fd6f1e44}
{#7362309ff2i0k}
7. Start the streaming job. {#d6e2005c0ed63}

   1. Click **Go to O\&M** .

      {#7219cb2a8amcm}
   {#5b61c6d858xvy}
   2. On the page that appears, click **Start** . In the Start Task dialog box, configure the Execution Queue parameter and click OK.

      {#26cf9a7d74mdt}
   {#531062e32636f}

   {#a335e29b49cs9}{#87df183ae2l8s}
{#87df183ae2l8s}

{#0327cfc43cdvi}

   {#ffcac5875dkq3}
{#da93013adbwwy}
2. On the Log Exploration tab, click **Driver Logs** . Then, click **stdOut.log** . {#a9b3d9f649rk8}

   In the log file, you can view information about the running of the application program and the returned results. {#f1c6d992d36rx}
