Use Paimon in EMR Serverless Spark {#bcea39f025a2t}
===================================================

Apache Paimon is a lake storage format that unifies streaming and batch processing. It supports high-throughput writes and low-latency queries. For more information, see [Apache Paimon](https://paimon.apache.org/){#7f3d2afde0rsd}. This topic describes how to read data from and write data to a Paimon table in EMR Serverless Spark.{#5354d7137afwe}

   * Catalog types{#0bd018b25ekrw}

     {#b42328030cgm3}{#6e53143ae9vco}{#304817493cxef}

     | **Type**       | **Description**                                                                                                                                                                                                                                                                                                                                                                                                          |
     | Paimon Catalog | Used to manage metadata in Paimon format.      | spark_catalog  | The default built-in catalog of Spark. It is typically used to manage metadata of internal tables in Spark SQL.    * Catalog configuration{#220f29290esiu}

     * Use Paimon Catalog{#b50a422bab6b5}

       **Important**

       In the configuration, `<catalogName>` is the name of the catalog. You can customize it. If you do not have special requirements, we recommend that you retain the default catalog name `paimon`.{#13f6386130ugn}

       DLF {#c8b270a8fdud4}
       --------------------

       Metadata is stored in DLF.{#803c786afbvud}

       ```properties
       spark.sql.extensions                            org.apache.paimon.spark.extensions.PaimonSparkSessionExtensions
       spark.sql.catalog.<catalogName>                 org.apache.paimon.spark.SparkCatalog
       spark.sql.catalog.<catalogName>.metastore       dlf
       ```

       {#5ea16c420c1x6}

       Hive {#5b7b5dbef8xr5}
       ---------------------

       Metadata is stored in a specified Hive MetaStore.{#7b79112e9bsmq}

       ```properties
       spark.sql.extensions                            org.apache.paimon.spark.extensions.PaimonSparkSessionExtensions
       spark.sql.catalog.<catalogName>                 org.apache.paimon.spark.SparkCatalog
       spark.sql.catalog.<catalogName>.metastore       hive
       spark.sql.catalog.<catalogName>.uri             thrift://<yourHMSUri>:<port>
       ```

       {#b7f3cc5b09xgi} {#9aacaae5e46v2}{#a7bddd316e6hc}

       |--------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
       | **Parameter**                  | **Description**                                                                                                                                                                                                                                                                                                                                                    |
       | `thrift://<yourHMSUri>:<port>` | The URI of the Hive MetaStore. The format is `thrift://<IP address of Hive metastore>:9083`.{#abf3dd5269fy3} `<IP address of Hive metastore>` is the internal IP address of the HMS service. If you need to specify an external Metastore service, see [Connect to an External Hive Metastore in EMR Serverless Spark](t2742024.md#ddf5ae70f6jpi){#ad9ccbda7c5nm}. |

       {#f7acc2f447d93}

       Filesystem {#d34df8c1b0oz2}
       ---------------------------

       Metadata is stored in a file system.{#863ca8fdb9olq}

       ```properties
       spark.sql.extensions                            org.apache.paimon.spark.extensions.PaimonSparkSessionExtensions
       spark.sql.catalog.<catalogName>                 org.apache.paimon.spark.SparkCatalog
       spark.sql.catalog.<catalogName>.metastore       filesystem
       spark.sql.catalog.<catalogName>.warehouse       oss://<yourBucketName>/warehouse
       ```

### **Step 2:** Read and write data to tables based on Paimon Catalog and spark_catalog {#d1e5dc16e2roy}

1. Go to the Development page of SQL.{#29bd7852f4biq}

   {#0203fcf8f53rp}
{#0203fcf8f53rp}
2. On the **Development** tab, click the ![image](../images/p916811.png) icon. {#336e9a4065j3m}

   {#1ce806c04b9hl}
{#1ce806c04b9hl}
3. In the **Create** dialog box, set the Name parameter to users_task, use the default value SparkSQL for the Type parameter, and then click **OK** . {#784fa8c065fo7}

   {#b6f0d65558qut}
{#b6f0d65558qut}
4. Copy the following code to the newly created Spark SQL tab (users_task).{#d6d26f11e17aq}

   Use Paimon Catalog {#274cb5c894bz7}
   -----------------------------------

   ```sql
   -- Create a database
   CREATE DATABASE IF NOT EXISTS paimon.ss_paimon_db;             
   
   -- Create a Paimon table
   CREATE TABLE paimon.ss_paimon_db.paimon_tbl (id INT, name STRING) USING paimon;
   
   -- Write data to the Paimon table
   INSERT INTO paimon.ss_paimon_db.paimon_tbl VALUES (1, "a"), (2, "b");
   
   -- Query data in the Paimon table
   SELECT * FROM paimon.ss_paimon_db.paimon_tbl ORDER BY id;
   
   -- Drop the database
   DROP DATABASE paimon.ss_paimon_db CASCADE;
   ```

   {#x61eyb}

   Use spark_catalog {#868e2f2e12ue1}
   ----------------------------------

   ```sql
   -- Create a database
   CREATE DATABASE IF NOT EXISTS ss_paimon_db; 
   CREATE DATABASE IF NOT EXISTS ss_parquet_db;
   
   -- Create a Paimon table and a Parquet table
   CREATE TABLE ss_paimon_db.paimon_tbl (id INT, name STRING) USING paimon;
   CREATE TABLE ss_parquet_db.parquet_tbl USING parquet AS SELECT 3, "c";
   
   -- Write data
   INSERT INTO ss_paimon_db.paimon_tbl VALUES (1, "a"), (2, "b");
   INSERT INTO ss_paimon_db.paimon_tbl SELECT * FROM ss_parquet_db.parquet_tbl;
   
   -- Query data from the Paimon table
   SELECT * FROM ss_paimon_db.paimon_tbl ORDER BY id;
   SELECT * FROM ss_parquet_db.parquet_tbl;
   
   -- Drop the database
   DROP DATABASE ss_paimon_db CASCADE;
   DROP DATABASE ss_parquet_db CASCADE;
   ```

**FAQ** {#feadf54250dcc}
------------------------

What should I do if an error occurs when I perform operations such as `DELETE`, `UPDATE`, or `MERGE` on a table?{#b83a0cd303f5r}

* Problem description: When you perform operations such as `DELETE`, `UPDATE`, or `MERGE`, an error message similar to the following one appears.{#01370f8aaaew9}

  ```bash
  Caused by: org.apache.spark.sql.AnalysisException: Table does not support deletes/updates/merge: <tableName>.
  at org.apache.spark.sql.errors.QueryCompilationErrors$.tableDoesNotSupportError(QueryCompilationErrors.scala:1391)
  ```

  {#b9219458dc35x} {#e0bf9cf131kii}
{#e0bf9cf131kii}
* Cause: The storage format of the table does not support row-level update operations or lacks necessary Spark configurations.{#18c7685800v1c}

  {#b98dc6c97ekdl}
{#b98dc6c97ekdl}
* Solution:{#78796d483a3yn}

  1. Check the table type.{#a54785594511k}

     Run the following command to check whether the table is a Paimon table.{#a9504c103dxrc}

     ```sql
     SHOW CREATE TABLE <tableName>;
     ```

     {#4139eed29dtmn}

     If the output contains `USING PAIMON`, the table is a Paimon table. If the output shows other storage formats such as `USING hive`, check whether the format supports row-level update operations.{#28ea6416deemu}
     {#a8cdbd098bb8f}
  {#a8cdbd098bb8f}
  2. Check the Spark configuration.{#1a51edb0e1qns}

     If the involved table is a Paimon table, check the **Spark Configuration** information to ensure that the following configuration is added to enable support for Paimon.{#1c404d7b66uv8}

     ```properties
     spark.sql.extensions org.apache.paimon.spark.extensions.PaimonSparkSessionExtensions
     ```

     {#12ce3dcaafx2a}

     If this configuration is not added, add it in the **Spark Configuration** .{#0e02c18306n0y}
     {#79ac28622ae27}
