Connect to EMR Serverless Spark and visualize data by using Livy Interpreter for Apache Zeppelin {#7069a7061dxul}
=================================================================================================================

Apache Zeppelin provides an interactive development environment that enables users to write code, run queries, and perform data visualization and analysis in a web UI. This topic describes how to connect to E-MapReduce (EMR) Serverless Spark by using Livy Interpreter for Apache Zeppelin to efficiently build and optimize an interactive development environment. {#e8bea21099wtc}

**Prerequisites** {#e6486ffba0dfe}
----------------------------------

* An EMR Serverless Spark workspace is created. For more information, see [Create a workspace](t2488607.md#){#3bdf17bfe2sex}.

  {#5326d6b819xcn}
{#3af810b673fzu}
* Apache Zeppelin is installed and started. For more information, see [Apache Zeppelin official documentation](https://zeppelin.apache.org/docs/latest/quickstart/install.html ""){#9734566400mlk}.

  {#9e3d4011b58qn}
{#9812e33cb8a2y}

{#09660de344krn}

**Procedure** {#5a734165bfqor}
------------------------------

### **Step 1: Create a gateway and a token** {#ad69c83b4ditg}

1. Create and start a gateway. {#c80f4561669rb}

   1. Go to the **Gateways** page. {#50a119bea0ipv}

      1. Log on to the [EMR console](https://emr-next.console.aliyun.com/#/region/cn-hangzhou/resource/all/overview){#b6d7c2902dddl}.

         {#8c27d43f80w5t}
      {#0c9092f954onh}
      2. In the left-side navigation pane, choose **EMR Serverless** \> **Spark** .

         {#b166c7854bir0}
      {#d514ca2d51e40}
      3. On the **Spark** page, find the desired workspace and click the name of the workspace.

         {#b166c7864bl2h}
      {#0155fba7b5y24}
      4. In the left-side navigation pane of the **EMR Serverless Spark** page, choose **Operation Center** \> **Gateways** .

         {#9e25305a07lmc}
      {#49b9129461rom}

      {#f15917c165edp}{#8dd11da13ehsq}
   {#8dd11da13ehsq}
   2. On the **Gateways** page, click the **Livy Gateways** tab.

      {#edc10294f1wbv}
   {#0c2d6ed9a6biy}
   3. On the **Livy Gateways** tab, click **Create Livy Gateway** .

      {#b4b947fecft4g}
   {#2b126888f8trg}
   4. On the Create Livy Gateway page, configure the **Name** parameter and click **Create** . In this example, set the **Name** parameter to Livy-gateway. {#6b64e37727wdk}

      You can configure other parameters based on your business requirements. For more information, see [Manage gateways](t2727015.md#){#3880e7fcdbk3c}.
      {#a36f57ad6brwa}
   {#f3a40b535d9bk}
   5. On the **Livy Gateways** tab, find the created gateway and click **Start** in the **Actions** column.

      {#957c784680nda}
   {#1c84c272c7cf6}

   {#c923654c4cwjh}{#d65c2e75bf2mc}
{#d65c2e75bf2mc}
2. Create a token. {#918e95438dfuj}

   1. On the **Gateways** page, find the gateway Livy-gateway and click **Tokens** in the Actions column.

      {#e813ca86c2lxf}
   {#9d90e354c6ww4}
   2. On the Tokens tab, click **Create Token** .

      {#c4bc703554ivt}
   {#def1ed2b8016w}
   3. In the **Create Token** dialog box, configure the **Name** parameter and click **OK** .

      {#8ed90c59ddim8}
   {#290d3533792im}
   4. Copy the token. {#d1d6aed6bc0iq}

      **Important**

      After the token is created, you must immediately copy the token. After you leave the page, you can no longer view the token. If your token expires or is lost, reset the token or create another token.
      {#824ef58af32bg}
   {#824ef58af32bg}

   {#5ba7aff7ddknq}{#a499d6d2beea3}
{#a499d6d2beea3}

{#39f9fbd15a29d}

### **Step 2: Configure Livy Interpreter for Apache Zeppelin** {#S6h8v}

1. Log on to Apache Zeppelin, click the username in the upper-right corner, and then select **Interpreter** from the drop-down list. {#33f17e349cpkj}

   ![image](../images/p904665.png)
   {#69944fce9a0lw}
{#1187b9817a6z0}
2. Click **+Create** in the upper-right corner and set the required parameters to create an interpreter. 

   {#09f2a7a5a16gz}{#acd7712483wkv}{#674b72b368tq1}

   |-----------------------|--------------------------------------|
   | **Parameter**         | **Description**                      |
   | **Interpreter Name**  | Enter a custom name, such as mylivy. |
   | **Interpreter Group** | Set this parameter to **livy** .     |

   {#65aa183f7225g}{#447bd26a1fhdh}
{#447bd26a1fhdh}
3. After you set the Interpreter Group parameter to **livy** , configure the required parameters. {#39b297f4f1bvy}

   ![image](../images/p904849.png){#66068fcb89nmv}

   The following table describes the required parameters. You can also configure other parameters based on your business requirements. For more information, see [Apache Zeppelin official documentation](https://zeppelin.apache.org/docs/latest/interpreter/jdbc.html ""){#147b53b773f0z}. {#e1fa699c9e5ot}
   {#204ad73ae0k0r}{#77f64d17b3l2e}{#638149857bndu}{#5446f81110z6t}

   |------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   | **Parameter**                            | **Description**                                                                                                                                                                                                                                 |
   | **zeppelin.livy.url**                    | The URL of the Livy gateway. Enter the URL in the `http://{endpoint}` format. `{endpoint}` indicates the **internal endpoint** of the Livy gateway that you created. {#c94936d9c0uz2} ![image](../images/p904837.png)                           |
   | **zeppelin.livy.session.create_timeout** | The maximum wait time for Apache Zeppelin to create a session. Unit: seconds. We recommend that you set this parameter to 600.                                                                                                                  |
   | **zeppelin.livy.http.headers**           | The custom header of the HTTP request. You need to click the ![image](../images/p904844.png) icon to add the configuration and enter `x-acs-spark-livy-token:{token}`. `{token}` is the token that you created on the **Token Management** tab. |

   {#d9b8a9593em57}{#24f649c928jqr}
{#24f649c928jqr}
4. Click **Save** in the lower part of the page to save the settings.

   {#fdef3daf4ewq1}
{#4d24ec8c533g4}

{#1a52b2055831j}

### **Step 3:** Create a notebook for data analytics {#MfiX6}

1. In the top navigation bar, click **Notebook** . Then, select **Create new note** .

   {#eeb7cea91f1ue}
{#6c64311046ixw}
2. Enter a custom note name and select mylivy from the Default Interpreter drop-down list. {#62a423f26a7s3}

   ![image](../images/p904712.png)
   {#82c1b3a58dc56}
{#b85f072046uav}
3. Click **Create** .

   {#fcb5bcd486pgo}
{#be3d9756d2xvz}
4. Enter the following code in the created notebook to start a Spark session. {#ed656d2c44cnu}

   The time required for the first startup is 1 to 3 minutes. If you enter `%pyspark`, the Python environment is used. If you enter `%spark`, the Scala environment is used. {#fc641c81e08za}

   ```python
   %pyspark
   ```

   {#65e5442adfl80}

   After the Spark session is started, you can view the link to the Spark UI and execute the code. You can use Python and Scala code together. {#d9acdae2168uf}

   ![image](../images/p904774.png)
   {#cc5302dfe1y7t}
{#31ffe427598kk}
5. Enter the following code in the new notebook to query the available databases in the current Spark environment. {#288657e995ibs}

   ```python
   %pyspark
   
   spark.sql("show databases").show()
   ```

   {#604f0cefb7xbt}

   The following figure shows the returned information. {#bfdebf6920e04}

   ![image](../images/p904784.png)
   {#3a3c2af07a9pf}
{#22ed364a54f7k}
6. Optional. View session information. {#de2a17ae589w3}

   After you create a Spark session by using the Livy interface, you can view information about the Spark session, such as the session ID and status, on the Sessions tab of a specified Livy gateway. {#ffb3dcda61qig}
   1. On the ******Livy Gateways****** tab, find the desired Livy gateway and click the name of the gateway.

      {#983c2d15cfk1a}
   {#06c98b8768feu}
   2. Click the **Sessions** tab. {#d88853117fnmq}

      On the Sessions tab, you can view information about the Spark session that is created by using the Livy interface. {#d213224948031}

      ![image](../images/p904793.png)
      {#db190d7b2b7c5}
   {#2b573f88d2k04}

   {#08bcbab6bc1k0}{#89c89ca2231l1}
