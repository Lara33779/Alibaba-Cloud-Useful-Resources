Use Iceberg in EMR Serverless Spark {#e1238bd226wpb}
====================================================

Iceberg is an open table format for data lakes. You can use Iceberg to quickly build your own data lake storage service on Hadoop Distributed File System (HDFS) or Alibaba Cloud Object Storage Service (OSS). This topic describes how to read data from and write data to an Iceberg table in EMR Serverless Spark. {#ecab2c52e15bz}

Prerequisites {#d0851f0fa449v}
------------------------------

A workspace is created. For more information, see [Create a workspace](t2488607.md#){#237c57d04cpoh}.

**Limits** {#c7743df155bo3}
---------------------------

You must add a Data Lake Formation (DLF) 1.0 catalog or an external Hive Metastore service as a catalog for your EMR Serverless Spark workspace.

Procedure {#3447a1e231ybc}
--------------------------

**Note**

You can use only a Spark SQL job or a notebook to read data from and write data to Iceberg tables. In this topic, a Spark SQL job is used.

### **Step 1: Create a session** {#96bb726b77h7a}

1. Go to the Sessions page. {#9c10d75ee20oh}

   1. Log on to the [EMR console](https://emr-next.console.aliyun.com/#/region/cn-hangzhou/resource/all/overview){#b6d7c2902dddl}.

      {#3628691aa3fy7}
   {#0f152a814bh9q}
   2. In the left-side navigation pane, choose **EMR Serverless** \> **Spark** .

      {#b166c7854bir0}
   {#0f152a834bqgu}
   3. On the **Spark** page, click the name of the workspace that you want to manage.

      {#b166c7864bl2h}
   {#0f152a854b8ko}
   4. In the left-side navigation pane of the **EMR Serverless Spark** page, choose **Operation Center** \> **Sessions** .

      {#c79985045dxzs}
   {#0f152a874bya0}

   {#f15917c165edp}{#a8c27cf24bg6w}
{#a8c27cf24bg6w}
2. On the **SQL Sessions** tab, click **Create SQL Session** .

   {#da24ced066cd3}
{#caa6ae8c0bqi1}
3. In the **Spark Configuration** section of the **Create SQL Session** page, add the following code and click **Create** . For more information, see [Manage SQL sessions](t2699789.md#){#2e0c67c4a9g94}. {#5c837f2bcarfj}

   DLF 1.0 {#b60572f463lfp}
   ------------------------

   ```xml
   spark.sql.extensions                           org.apache.iceberg.spark.extensions.IcebergSparkSessionExtensions
   spark.sql.catalog.iceberg                      org.apache.iceberg.spark.SparkCatalog
   spark.sql.catalog.iceberg.catalog-impl         org.apache.iceberg.aliyun.dlf.hive.DlfCatalog
   ```

   {#0828e975a60ox}

   Hive Metastore {#db7bb71102ber}
   -------------------------------

   ```xml
   spark.sql.extensions                           org.apache.iceberg.spark.extensions.IcebergSparkSessionExtensions
   spark.sql.catalog.iceberg                      org.apache.iceberg.spark.SparkCatalog
   spark.sql.catalog.iceberg.catalog-impl         org.apache.iceberg.hive.HiveCatalog
   ```

   {#a2de995575eup}{#d6ed0ec5845j6}
{#d6ed0ec5845j6}
4. Find the created session and click **Start** in the Actions column.

   {#7470945ade5ft}
{#85bbf03111zj0}

{#5edbe5fe9cutf}

### **Step 2: Read data from and write data to an Iceberg table** {#70e87ec143i28}

1. Go to the data development page of EMR Serverless Spark. {#24d0a4e13ce9u}

   In the left-side navigation pane of the **EMR Serverless Spark** page, click **Data Development** .
   {#42543ba9bel3c}
{#0203fcf8f53rp}
2. On the **Development** tab, click the ![image](../images/p916811.png) icon.

   {#336e9a4065j3m}
{#1ce806c04b9hl}
3. In the **Create** dialog box, set the Name parameter to users_task, use the default value SparkSQL for the Type parameter, and then click **OK** .

   {#784fa8c065fo7}
{#b6f0d65558qut}
4. On the users_task tab, copy the following code to the code editor: {#e180da6f13a0y}

   ```sql
   CREATE DATABASE IF NOT EXISTS iceberg.ss_iceberg_db;
   
   CREATE TABLE iceberg.ss_iceberg_db.iceberg_tbl (id INT, name STRING) USING iceberg;
   
   INSERT INTO iceberg.ss_iceberg_db.iceberg_tbl VALUES (1, "a"), (2, "b");
   
   SELECT id, name FROM iceberg.ss_iceberg_db.iceberg_tbl ORDER BY id;
   ```

   {#9b7b2caeb155i}

   You can run the following commands to drop the table and database if you no longer need them. {#bc50165e1dm74}

   ```sql
   DROP TABLE iceberg.ss_iceberg_db.iceberg_tbl;
   
   DROP DATABASE iceberg.ss_iceberg_db;
   ```

   {#af776dd89fmtz}{#910db9b2dfaw6}
{#910db9b2dfaw6}
5. Select a database from the Default Database drop-down list and the created SQL session from the SQL Sessions drop-down list.

   {#395fc0dc69gam}
{#76addbae29qjj}
6. Click **Run** . The following figure shows the output. {#8d14c717e7hhu}

   ![image](../images/p850116.png)
   {#90ba525554akm}
{#161838724e9f5}
