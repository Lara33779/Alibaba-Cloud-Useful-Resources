Use Jupyter Notebook to interact with EMR Serverless Spark {#da1ae1258edhl}
===========================================================================

Jupyter Notebook is a powerful interactive development tool that allows you to write and run code via a web interface and view results in real time, eliminating the need for precompilation or separate script execution. This topic describes how to efficiently establish a development environment for EMR Serverless Spark interaction.{#ead6bae35923v}

**Background information** {#40c94c9ede9zm}
-------------------------------------------

Apache Livy facilitates Spark interaction through RESTful API calls, streamlining communication between Spark and the application server. For more information about the Livy API, see [REST API](https://livy.incubator.apache.org/docs/latest/rest-api.html ""){#f7d6f688440yd}.{#6164da3a66t0i}

Jupyter Notebook offers various methods to interact with EMR Serverless Spark, as detailed in the table below. Select a method based on your business needs.{#4bc5dadb7bobw}
{#4a4cff5795ney}{#3ad753e49aoc1}{#08a51d0796zhx}

|------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Method**                                                                                     | **Scenarios**                                                                                                                                                                                                                                                                                    |
| [Method 1: Quickly start the environment using a Docker image](#e701aed8e1ou3){#05d8285b904qs} | Choose this method to rapidly establish a standalone development environment or to replicate identical settings across different machines.                                                                                                                                                       |
| [Method 2: Start the environment using the sparkmagic plug-in](#494d5d23ffzuj){#c330180470c8e} | The sparkmagic plug-in for Jupyter Notebook interacts with Spark through RESTful APIs and supports Livy, Livy Lighter, and Ilum protocols. Configure the sparkmagic plug-in and invoke EMR Serverless Spark's Livy API to create a development environment for remote Spark cluster interaction. |

{#42b87cfe1e9ez}

**Method 1: quickly start the environment by using a Docker image** {#e45389ea1dp96}
------------------------------------------------------------------------------------

### **Step 1: Create a gateway and access token** {#f269f6af9dj5x}

1. Create and start a gateway. {#c80f4561669rb}

   1. Go to the **Gateways** page. {#50a119bea0ipv}

      1. Log on to the [EMR console](https://emr-next.console.aliyun.com/#/region/cn-hangzhou/resource/all/overview){#b6d7c2902dddl}.

         {#8c27d43f80w5t}
      {#0c9092f954onh}
      2. In the left-side navigation pane, choose **EMR Serverless** \> **Spark** .

         {#b166c7854bir0}
      {#d514ca2d51e40}
      3. On the **Spark** page, find the desired workspace and click the name of the workspace.

         {#b166c7864bl2h}
      {#0155fba7b5y24}
      4. In the left-side navigation pane of the **EMR Serverless Spark** page, choose **Operation Center** \> **Gateways** .

         {#9e25305a07lmc}
      {#49b9129461rom}

      {#f15917c165edp}{#8dd11da13ehsq}
   {#8dd11da13ehsq}
   2. On the **Gateways** page, click the **Livy Gateways** tab.

      {#edc10294f1wbv}
   {#0c2d6ed9a6biy}
   3. On the **Livy Gateways** tab, click **Create Livy Gateway** .

      {#b4b947fecft4g}
   {#2b126888f8trg}
   4. On the Create Livy Gateway page, configure the **Name** parameter and click **Create** . In this example, set the **Name** parameter to Livy-gateway. {#6b64e37727wdk}

      You can configure other parameters based on your business requirements. For more information, see [Manage gateways](t2727015.md#){#3880e7fcdbk3c}.
      {#a36f57ad6brwa}
   {#f3a40b535d9bk}
   5. On the **Livy Gateways** tab, find the created gateway and click **Start** in the **Actions** column.

      {#957c784680nda}
   {#1c84c272c7cf6}

   {#c923654c4cwjh}{#d65c2e75bf2mc}
{#d65c2e75bf2mc}
2. Create a token. {#918e95438dfuj}

   1. On the **Gateways** page, find the gateway Livy-gateway and click **Tokens** in the Actions column.

      {#e813ca86c2lxf}
   {#9d90e354c6ww4}
   2. On the Tokens tab, click **Create Token** .

      {#c4bc703554ivt}
   {#def1ed2b8016w}
   3. In the **Create Token** dialog box, configure the **Name** parameter and click **OK** .

      {#8ed90c59ddim8}
   {#290d3533792im}
   4. Copy the token. {#d1d6aed6bc0iq}

      **Important**

      After the token is created, you must immediately copy the token. After you leave the page, you can no longer view the token. If your token expires or is lost, reset the token or create another token.
      {#824ef58af32bg}

1. Execute the following command to pull the image.{#de35fe8d717p0}

   ```bash
   docker pull emr-registry-registry.cn-hangzhou.cr.aliyuncs.com/serverless-spark-public/emr-spark-jupyter:latest
   ```

### **Step 3:** Configure and start an interactive Spark session {#98b1e2b455gge}

1. Access Jupyter's UI. For details, see [JupyterLab](https://jupyterlab.readthedocs.io/en/stable/ ""){#1ed36d3ad2xtn}.

   {#c9c2b1a317ch7}
{#e03ea8a7366xm}
2. Incorporate the sparkmagic plug-in.{#610d76f5ebnm0}

   ```python
   %load_ext sparkmagic.magics
   ```

   {#eb4fca1b33xo8}{#78be453cfe5re}
{#78be453cfe5re}
3. Adjust the session configuration.{#9c362fe82a1pc}

   1. Extend the startup timeout to avoid timeout errors due to resource scheduling delays.{#a08cf5b80alr5}

      ```python
      import sparkmagic.utils.configuration as conf
      conf.override("livy_session_startup_timeout_seconds", 1000)
      ```

      {#824b0f1c1ajvs}{#051c68351e6au}
   {#051c68351e6au}
   2. (Optional) Tailor the Spark resource settings.{#1fb3ebd9bf7cd}

      Add parameters like ttl and conf as needed. For more information, consult [Livy Docs - REST API](https://livy.incubator.apache.org/docs/latest/rest-api.html){#bce1d953b9io6}.{#a0ea306b117ev}

      For instance, the following configuration modifies the driver's resource settings.{#7b62efe4b8seg}

      ```python
      %% spark config
      {
        "conf": {
              "spark.driver.cores": "1",
              "spark.driver.memory": "7g"
               }
      }
      ```

      {#bc28de6bdeaxj}{#bdc17b4979cw9}
   {#bdc17b4979cw9}

   {#1b2f299ac0760} {#cda0b4961fw7p}
{#cda0b4961fw7p}
4. Initiate a session.{#ed9dc92b64bmg}

   ```python
   %spark add -s <session_name> -l python -u https://<endpoint> -a username -p <token>
   ```

   {#ed5f0f5e5as7w}

   Modify the following details to suit your requirements.{#05aae1ce44oyw}
   {#acf012b11cnkd}{#965e31f723sai}{#42ea8c50cbxz5}{#55e228de19x7z}

   |------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
   | **Parameter**    | **Description**                                                                                                                                                                                                                                                                                                         |
   | `<session_name>` | The name of the Spark session. You can enter a custom name.                                                                                                                                                                                                                                                             |
   | `<endpoint>`     | The **Endpoint (internet)** or **Endpoint (intranet)** that you obtain from the **Overview** tab.{#c94936d9c0uz2} If you use the intranet endpoint, make sure that the machine on which Jupyter runs and the Livy gateway are deployed in the same region. In addition, change `https://` to `http://` in the endpoint. |
   | `<token>`        | The token that you copy from Step 1.                                                                                                                                                                                                                                                                                    |

   {#9dd803cc0fjq1}

   You will receive the following response.{#b7324e74fbg8k}

   ![image](../images/p920499.png){#8efdf6b188q0g}

   Wait for 1 to 5 minutes until the session status turns to `idle`, indicating the session is ready. Session details will appear on the UI, and you can begin interactive development with PySpark. Session information is also visible on the **Session List** tab of the Livy gateway in the EMR Serverless Spark console.
   {#380a3763013zj}
{#3a1faebe0d00q}
5. Confirm the session.{#272747c7f65jb}
