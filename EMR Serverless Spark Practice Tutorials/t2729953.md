Use the spark-submit CLI to submit a Spark job {#8e4d98beceomt}
===============================================================

This topic describes how to use the spark-submit CLI to submit a Spark job after E-MapReduce (EMR) Serverless Spark is connected to Elastic Compute Service (ECS). {#bb683773548t9}

Prerequisites 
----------------------------------

* Java Development Kit (JDK) V1.8 or later is installed.

  {#5c5228d802dqx}
{#a71e8884c7mh0}
* If you want to use a RAM user to submit Spark jobs, make sure that the RAM user is added to a Serverless Spark workspace as a member and assigned the developer role or a role that has higher permissions. For more information, see [Manage users and roles](t2499901.md#){#1327be959f0p4}.

  {#f34fb3cfb520p}
{#fa0d770cd1kwr}

{#e6ffc7d647rwb}

**Procedure** {#f1c028b14dh0h}
------------------------------

### **Step 1: Download and install the spark-submit tool for EMR Serverless** {#6ad21590162l0}

1. Click [emr-serverless-spark-tool-0.2.0-bin.zip](https://help-static-aliyun-doc.aliyuncs.com/file-manage-files/en-US/20241106/mowykw/emr-serverless-spark-tool-0.2.0-bin.zip){#6fd403e39f3g3} to download the installation package.

   {#eb6229063emku}
{#a3d0b5b3f8rve}
2. Upload the installation package to an ECS instance. For more information, see [Upload and download files](t2277235.md#){#3c77740ed19eg}.

   {#20379e20f61bf}
{#8426ee551dnjq}
3. Run the following command to decompress the installation package and install the spark-submit tool: {#eb8aa79c1fdhh}

   ```sh
   unzip emr-serverless-spark-tool-0.2.0-bin.zip
   ```

   {#a94f7dce91lpe}{#780264673758v}
{#780264673758v}

{#309ecc11castb}

### **Step 2: Configure parameters** {#f76363b126nyc}

**Important**

If the `SPARK_CONF_DIR` environment variable is configured in the environment in which the spark-submit tool is installed, you must store the configuration file in the directory specified by the `SPARK_CONF_DIR` environment variable. For example, for EMR clusters, the directory is `/etc/taihao-apps/spark-conf` in most cases. Otherwise, an error is reported.

1. Run the following command to modify the configuration of the connection.properties file: {#b3ad1284c0eiq}

   ```sh
   vim emr-serverless-spark-tool-0.2.0/conf/connection.properties
   ```

   {#bbfe5b165a611}{#65fa70db8cw3x}
{#65fa70db8cw3x}
2. Configure parameters in the file based on the following sample code. The parameters are specified in the `key=value` format. {#b6158ba2b9978}

   ```sh
   accessKeyId=yourAccessKeyId
   accessKeySecret=yourAccessKeySecret
   # securityToken=yourSecurityToken
   regionId=cn-hangzhou
   endpoint=emr-serverless-spark.cn-hangzhou.aliyuncs.com
   workspaceId=w-xxxxxxxxxxxx
   resourceQueueId=dev_queue
   # networkServiceId=xxxxxx
   releaseVersion=esr-2.2 (Spark 3.3.1, Scala 2.12, Java Runtime)
   ```

   {#0ef26c9cf5e4d}

### **Step 3: Submit a Spark job** {#a97fae6d21u8i}

1. Run the following command to go to the directory of the spark-submit tool: {#b57a49cd2374p}

   ```sh
   cd emr-serverless-spark-tool-0.2.0
   ```

   {#bf59c083edac2}{#d1646d5b7fjvg}
{#d1646d5b7fjvg}
2. Submit the Spark job. {#7d8451366clq8}

   Spark job launched from Java or Scala {#7df3e623176wq}
   ------------------------------------------------------

   In this example, the test JAR package spark-examples_2.12-3.3.1.jar is used. You can click [spark-examples_2.12-3.3.1.jar](https://help-static-aliyun-doc.aliyuncs.com/file-manage-files/zh-CN/20240207/cmalbs/spark-examples_2.12-3.3.1.jar ""){#9d762b1592ayj} to download the test JAR package. Then, you can upload the JAR package to Object Storage Service (OSS). The JAR package is a simple example provided by Spark to calculate the value of pi (π). {#10d0a7dfe802t}

   ```java
   ./bin/spark-submit  --name SparkPi \
   --queue dev_queue  \
   --num-executors 5 \
   --driver-memory 1g \
   --executor-cores 2 \
   --executor-memory 2g \
   --class org.apache.spark.examples.SparkPi \
    oss://<yourBucket>/path/to/spark-examples_2.12-3.3.1.jar \
   10000
   ```

   {#58bf62a03cd25}

   Spark job launched from PySpark {#10e7026e54pfv}
   ------------------------------------------------

   In this example, the test files DataFrame.py and employee.csv are used. You can click [DataFrame.py](https://help-static-aliyun-doc.aliyuncs.com/file-manage-files/zh-CN/20240418/mzftlh/DataFrame.py ""){#81f3dc008d0kg} and [employee.csv](https://help-static-aliyun-doc.aliyuncs.com/file-manage-files/zh-CN/20240418/ktzzqn/employee.csv ""){#6e25146d68l5x} to download the test files. Then, you can upload a JAR package that contains the files to OSS. {#eaf6ba3afb1q6}
   **Note**
   * The DataFrame.py file contains the code that is used to process data in Object Storage Service (OSS) under the Apache Spark framework.

     {#0e88e5bb47p9m}
   {#27a7ac69e9xw7}
   * The employee.csv file contains data such as employee names, departments, and salaries.

     {#0de7f1177979k}
   {#f3977bec25kze}

   {#3e01642c40pyw}

   ```python
   ./bin/spark-submit --name PySpark \
   --queue dev_queue  \
   --num-executors 5 \
   --driver-memory 1g \
   --executor-cores 2 \
   --executor-memory 2g \
   --conf spark.tags.key=value \
   --files oss://<yourBucket>/path/to/employee.csv \
   oss://<yourBucket>/path/to/DataFrame.py \
   10000
   ```

### **Step 4:** Query the Spark job {#678505d845vzw}

Use the CLI {#7cfa6d328anta}
----------------------------

#### **Query the status of the Spark job** {#NWnqa}

```sh
cd emr-serverless-spark-tool-0.2.0
./bin/spark-submit --status <jr-8598aa9f459d****>
```

{#577edd46d5e46}

#### **View the details of the Spark job** {#PTHHh}

```sh
cd emr-serverless-spark-tool-0.2.0
./bin/spark-submit --detail <jr-8598aa9f459d****>
```

{#06c6d52247t6u}

Use the UI {#85a1880fcfo3a}
---------------------------

1. In the left-side navigation pane of the **EMR Serverless Spark** page, click **Job History** .

   {#43b3c61c42m30}
{#3baefcebd8jbd}
2. On the **Job History** page, click the **Development Job Runs** tab. Then, you can view all submitted jobs. {#b7fb506b06xam}

   ![image](../images/p809909.png)
   {#e4369e8bf6ru6}
{#58145096e08ym}

### **(Optional) Step 5:** Terminate the Spark job {#d82eb8d9404if}

```sh
cd emr-serverless-spark-tool-0.2.0
./bin/spark-submit --kill <jr-8598aa9f459d****>
```

{#16b2a2fe76pf1}
**Note**

You can terminate only a job that is in the Running state.
